 QUEST, MATCH AND LEARN PUZZLE CHALLENGE

An Educational Tile-Matching Puzzle Game — Learn by Matching, Solving, and Answering!**


 About the Project

Quest, Match and Learn Puzzle Challenge** is a fun educational puzzle game where players match tiles to complete a hidden puzzle, then answer quiz questions to test what they've learned. Complete levels, earn points, and unlock new challenges


 Game Concept

| Item | Details |
|------|---------|
| **Title** | Quest, Match and Learn Puzzle Challenge |
| **Theme** | Respiratory System — Science Education |
| **Genre** | Educational Puzzle Game |
| **Platform** | Mobile & Desktop Web |
| **Core Loop** | Match Tiles → Reveal Puzzle → Answer Quiz → Earn Points → Pass Level → Next Level |


How to Play

1. Select a Level — Choose your challenge
2. Match the Tiles — Find and click matching pairs
3. Complete the Puzzle — Reveal the hidden image
4. Answer the Quiz — Test your knowledge
5. Earn Points & Progress — Pass and unlock new levels
